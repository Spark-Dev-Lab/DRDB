# Brochure/Recruitment Tracking Implementation Summary

## Overview
Implemented a complete pipeline to track brochure and flyer recruitment information from Google Forms. The system displays three key tracking fields (read-only, populated via Google Forms import only):

1. **RecruitmentMethod** (existing) - How they heard about us
2. **BrochureSeen** (new) - Have they seen our brochures or flyers? (Yes/No/Unsure)
3. **BrochureLocation** (new, conditional) - Where did they see/receive it? (multiple options)

**Important**: These fields are **read-only display fields** populated from Google Forms import. They cannot be edited manually in the UI.

### 6. Data Flow Architecture (Import → Display)
```
Google Forms Response
    ↓ (Contains: RecruitmentMethod, BrochureSeen, BrochureLocation)
    ↓
Google Form Importer (your process)
    ↓ (Transforms form data to API format)
    ↓
API: POST /api/family/importIntakeForms
    ↓ (Receives structured data with recruitment fields)
    ↓
Backend: family.create() or family.update()
    ↓
Database: Family table (stores all three fields)
    ↓
Frontend: Household info view
    ↓ (Display-only section shows recruitment info with chips)
    ↓
User sees: RecruitmentMethod + BrochureSeen + BrochureLocation
```

**Note**: Users cannot edit these fields; they are populated only from Google Forms import.

## Known Considerations

1. **Backwards Compatibility**: Existing family records will have NULL for new fields until updated
2. **JSON Parsing**: Implemented with try/catch to handle gracefully if JSON is malformed
3. **Array vs String**: BrochureLocation is stored as JSON array to support multiple selections
4. **Nullable**: All new fields are nullable (allowNull: true) for optional tracking
5. **Import Flexibility**: Import endpoint will accept either array or string values for BrochureLocation

### Helper Method (Safe JSON Parsing)
```javascript
parseJsonArray(value) {
  if (!value) return [];
  if (Array.isArray(value)) return value;
  try {
    return JSON.parse(value) || [];
  } catch {
    return [];
  }
}
```
